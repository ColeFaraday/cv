# Read the shared guide first

This repo is one half of a two-repo setup (`cv/` + `colefaraday.github.io/`).
Before adding a paper, adding a talk, or publishing anything, read:

    ../CLAUDE.md

It covers what `make stage` does and does not sync, the bibtex field
reference for `papers.bib` and `talks.bib`, the `entrysubtype` values that
control CV sections, where slides / preview images / paper PDFs must live,
and the branch + deploy flow. Changes in this repo alone are usually not
enough — most tasks touch both.
